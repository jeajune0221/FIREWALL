# AI 도자기 판매 지원 서비스 — 수정 기능 명세

> 이 문서는 기능 단위 상세 명세다. MVP 범위/우선순위/금지 규칙이 이 문서와 다르게 보일 경우 `DEV.md`를 기준으로 삼는다. (본 수정에서 두 문서의 상충 항목을 DEV.md 기준으로 맞췄다.)

## 1. 서비스 목표

베트남 도자기 공예가가 제품 사진과 간단한 설명만 입력하면, AI가 제품 특징과 문양 후보를 분석하고 장인의 확인을 거쳐 판매용 콘텐츠를 자동 생성하는 모바일 웹서비스.

핵심 목표는 다음과 같다.

- 제품 설명 작성 시간 단축
- 외국인 고객을 위한 설명 생성
- SNS·온라인 판매용 콘텐츠 제작 자동화
- 잘못된 문화 설명이 생성되는 위험 최소화

---

# 2. 핵심 사용자

## Persona

**Bát Tràng 등에서 소규모 도자기 공방 또는 상점을 운영하는 베트남 도예가**

### 가설

- 직접 도자기를 제작하거나 판매함
- 제품마다 문양과 제작 이야기를 설명해야 함
- Facebook, TikTok, Shopee 등의 온라인 채널을 활용할 가능성이 있음
- 제품 소개글과 외국어 콘텐츠 제작에 시간이 필요함

> 나이, 디지털 숙련도, 실제 판매 채널 등은 사용자 인터뷰를 통해 검증한다.

---

# 3. 핵심 문제

## Problem 1 — 반복적인 제품 설명

도예가는 제품마다 다음 내용을 반복적으로 설명해야 한다.

- 제품 특징
- 문양
- 문양의 의미
- 제작 과정
- 작품에 담긴 이야기

특히 젊은 고객이나 외국인 고객에게는 추가적인 설명이 필요하다.

---

## Problem 2 — 온라인 콘텐츠 제작

온라인에서 제품을 판매하거나 홍보하기 위해서는 다음 작업이 필요하다.

- 제품 사진 준비
- 제품명 작성
- 상품 설명 작성
- 작품 스토리 작성
- SNS 콘텐츠 작성
- 외국어 번역

이 과정은 도자기 제작과 별개의 반복 업무다.

# 4. 핵심 사용자 Flow

```text
도자기 사진 업로드
        ↓
AI 이미지 분석
        ↓
제품 특징 + 문양 후보 제시
        ↓
[장인 확인 단계]
문양 후보 확인 / 수정 / 삭제
        ↓
장인의 추가 설명 입력
(음성 또는 텍스트)
        ↓
AI 콘텐츠 생성
(선택한 언어로 직접 생성, 번역 후처리 아님)
        ↓
판매용 설명 / SNS / 매장용 콘텐츠
        ↓
vi / en / ko 중 선택 → 해당 언어로 재생성
        ↓
복사하여 원하는 플랫폼에 사용
```

# 5. 기능 1 — 도자기 이미지 분석

## 입력

- 도자기 제품 사진

## OpenAI 역할

Vision 모델을 사용하여 사진에서 다음 정보를 추출한다.

- 제품 종류
- 색상
- 형태
- 장식 요소
- 문양 후보
- 눈에 띄는 특징

## 예시

```json
{
  "product_type": "vase",
  "colors": ["blue", "white"],
  "pattern_candidates": ["lotus"],
  "features": [
    "symmetrical decoration",
    "blue-and-white ceramic style"
  ]
}
```

### 중요

AI 분석 결과를 바로 상품 설명 생성에 사용하지 않는다.

반드시 **사용자 검증 단계**를 거친다.

---

# 6. 기능 2 — 문양 확인 및 수정

AI가 인식한 문양 후보를 장인에게 보여준다.

## 화면 예시

```text
AI가 다음 문양을 발견했습니다.

● 연꽃 (Hoa sen)
  Confidence: High

○ 등록된 다른 문양에서 선택
○ 해당 없음

[확인하고 계속]
```

장인은 다음 행동을 할 수 있다.

- AI 분석 결과 확인
- 등록된 문양 목록 중 다른 문양으로 변경
- 일치하는 문양이 없으면 "해당 없음" 선택

이 단계를 통해 잘못된 AI 분석이 이후 콘텐츠에 그대로 전달되는 것을 줄인다.

### 중요

MVP에서는 자유 텍스트로 새 문양을 추가하지 않는다. 문양은 항상 사전에 검증된 Pattern Database 목록 안에서만 선택한다. (자유 입력을 허용하면 문화 설명 hallucination 위험이 커진다 — 자세한 내용은 `DEV.md` 11번 항목 참고)

---

# 7. 문양 데이터

MVP에서는 대규모 문화 데이터베이스나 RAG를 사용하지 않는다.

대신 약 **10~20개의 주요 베트남 전통 문양 데이터**를 직접 준비한다.

## 예시 구조

| 문양 | Vietnamese | 설명 | 문화적 의미 | 출처 |
|---|---|---|---|---|
| 연꽃 | Hoa sen | 베트남에서 자주 사용되는 전통 문양 | 순수함, 평온함 | (조사 담당자가 출처 확인 후 기입) |
| 용 | Rồng | 전통 예술에서 사용되는 상징 | 권위, 힘 | (조사 담당자가 출처 확인 후 기입) |
| 대나무 | Tre | 생활과 예술에서 자주 등장 | 강인함 | (조사 담당자가 출처 확인 후 기입) |

AI에게 이 정보를 함께 제공한다.

### 중요

출처가 확인되지 않은 문양과 의미는 DB에 등록하지 않는다. 각 항목은 반드시 출처(기관, 자료명, URL 등)를 함께 기록한다.

### 제한

등록되지 않은 문양에 대해서는 AI가 임의로 확정하지 않는다.

예:

```text
이 문양에 대한 검증된 정보가 없습니다.
장인이 직접 설명을 추가해주세요.
```

# 8. 기능 3 — 장인 설명 입력

사용자는 두 가지 방법으로 작품 설명을 입력할 수 있다.

### Option A — 음성 입력

버튼을 누르고 작품에 대해 자유롭게 말한다.

예:

```text
이 작품은 제가 어릴 때 보았던 연꽃을 생각하면서 만들었습니다.
```

STT를 사용해 텍스트로 변환한다.

### Option B — 직접 입력

음성 인식이 정확하지 않을 경우 직접 텍스트를 입력하거나 수정할 수 있다.

> 음성 입력은 편의 기능이며 필수 입력 방식이 아니다.

---

# 9. 기능 4 — 제품 스토리 생성

## OpenAI 입력

```text
제품 특징
+
장인이 확인한 문양
+
검증된 문양 정보
+
장인의 설명
```

## OpenAI 출력

자연스러운 제품 스토리를 생성한다.

예:

```text
이 작품은 장인이 어린 시절 보았던 연꽃에서 영감을 받아 제작되었습니다.

푸른색과 흰색의 조화를 활용하여 전통적인 분위기를 표현했으며,
연꽃 문양을 작품의 중심 요소로 사용했습니다.
```

# 10. 기능 5 — 용도별 콘텐츠 생성

사용자가 플랫폼을 선택하는 단계는 두지 않는다. 한 번의 생성 요청으로 아래 형식을 모두 함께 받아 결과 화면에 한 번에 보여준다. (필요한 것만 골라 복사해서 쓰면 된다)

```text
- 온라인 상품 설명 (product_description)
- SNS 게시글 (social_post)
- 매장 / QR용 짧은 설명 (short_description)
```

AI는 동일한 검증 데이터를 기반으로 콘텐츠마다 길이와 스타일만 다르게 생성한다.

### 온라인 상품 설명

- 제품 특징 중심
- 비교적 상세한 설명

### SNS

- 짧은 문장
- 이야기 중심
- 관심을 끌 수 있는 첫 문장

### 매장 설명

- 짧고 이해하기 쉬운 설명
- QR 페이지 등에 활용 가능

# 11. 기능 6 — 다국어 콘텐츠

MVP 지원 언어:

- Vietnamese
- English
- Korean

5개 이상의 언어를 지원하지 않고, 팀원이 직접 결과를 검수할 수 있는 언어만 우선 지원한다.

콘텐츠를 한 번 생성한 뒤 번역하는 방식이 아니라, 생성 요청에 `target_language`를 넣어 해당 언어로 직접 생성한다. 그래서 단순 직역투가 아니라 외국인이 자연스럽게 이해할 수 있는 표현이 나온다. (자세한 동작은 `DEV.md` 26번 항목 참고)

# 12. 이미지 보정 — MVP 제외 기능

배경 제거, 밝기/대비 자동 보정 등 이미지 편집 기능은 **MVP 범위에서 제외**한다.

이유: 하루 개발 범위를 벗어나고, 서비스의 핵심 가치(정확한 문화 정보 + 장인 검증)와 직접 관련이 없다.

업로드된 원본 사진을 그대로 사용한다. (시간이 남으면 고려할 수 있는 Post-MVP 후보 기능)

# 13. 장인 스타일 개인화 — Future Feature

MVP에서는 실제 모델 학습을 하지 않는다.

장인의 기존 상품 설명 몇 개를 저장해 OpenAI 요청 시 예시로 함께 전달하는 **Few-shot Example 방식**을 사용한다.

```text
장인이 이전에 작성한 설명 예시

Example 1
Example 2
Example 3

↓

AI Prompt에 함께 제공
```

장인이 AI 결과를 수정한 경우 향후 예시 데이터로 사용할 수 있다.

### 목적

AI가 생성하는 모든 글이 동일한 문체가 되는 것을 방지한다.

# 14. AI Workflow Automation

본 서비스는 완전한 Autonomous AI Agent가 아니라 **AI Workflow Automation** 구조를 사용한다.

```text
IMAGE
 ↓
Vision Analysis
 ↓
Product Features
 ↓
Pattern Candidates
 ↓
USER VALIDATION
 ↓
Verified Pattern
 +
Craftsman's Story
 +
Target Language (vi/en/ko)
 ↓
AI Content Generation
(해당 언어로 직접 생성)
 ↓
Platform Formatting
 ↓
Final Content
```

AI가 독립적으로 행동을 결정하는 구조가 아니라, 정해진 업무 흐름의 일부를 자동화한다.

→ 색상

## ② Speech-to-Text

장인의 음성을 텍스트로 변환

```text
Voice
→ Text
```

실패 시 직접 텍스트 입력 가능.

---

## ③ LLM

검증된 정보를 기반으로 콘텐츠 생성

```text
Verified Product Data
+
Craftsman's Story

→ Product Description
→ Story
→ SNS Content
```

---

## ④ 다국어 생성

번역을 별도 후처리로 수행하지 않는다. 콘텐츠 생성 요청에 `target_language`를 함께 전달해 처음부터 해당 언어로 직접 생성한다.

```text
target_language: vi | en | ko
```

결과 화면에서 다른 언어 버튼을 누르면, 이미 생성된 텍스트를 번역하는 것이 아니라 동일한 검증 데이터로 `target_language`만 바꿔 생성 API를 다시 호출한다.

# 21. 한 줄 설명

> **베트남 도예가가 작품 사진과 간단한 설명만 입력하면, AI 분석과 장인의 검증을 거쳐 신뢰할 수 있는 판매 콘텐츠를 자동으로 만들어주는 서비스.**
